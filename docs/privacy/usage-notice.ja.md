# 利用統計に関するプライバシー通知（草案）

この文書は法務レビュー前のプレースホルダーです。法務部門が確定するまで、製品のプライバシー方針としては扱いません。

## 収集するもの

オプトインが有効で、かつ送信先がプレースホルダーでない場合に限り、次の項目だけを送信します。

- ランダムなインストール ID（設定画面から再生成できます）
- アプリのバージョン
- 粗い OS 区分（macOS、Windows、Linux、その他）
- イベント名と回数（利用した機能、粗いエラーコード）

## 収集しないもの

プロンプト本文、ファイル名、パス、モデルの出力、患者情報、その他の自由記述は送信しません。識別子は、再生成できるランダムなインストール ID 以外を含みません。

## 既定

オプトインの既定はオフです。送信先が `https://stats.REPLACE_ME/dra/usage` の間は、オプトインがオンでも送信しません。
