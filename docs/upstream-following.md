- 跟随上游新增 GWAS 摘要统计检索、InterProScan 序列提交和 IEDB TCR/BCR 证据连接器，以及 Requesty 模型提供方配置。这些连接器已包含在源码和测试中，外部服务真实调用未验证。
- 新会话建议与会话常用操作菜单；导入会话只读、回放后继续讨论和输入上下文相关修复。
- PDF 文档与批注身份统一，数据库结构更新；Notebook 依赖关系、损坏运行记录恢复及运行环境相关修复。
- 保留 DRA / AI Research Infrastructure for Medicine 两行品牌、Auth0、管理员会员、Plus $20/月、Pro $100/月、原六入口、证据表、Notebook、论文组织、研究审阅包、三专家与问题记录、本地使用汇总和 Windows 长路径保存修复。支付未接入。
